# OpenCode overlay

Use `.opencode/agents/stickman-director.md` or `.opencode/agents/stickman-reviewer.md`; each points to `agent/SKILL.md` and selects exactly one role heading: `director-orchestrator` or `reviewer`. These profiles intentionally use `mode: primary` for owner-controlled manual invocation and do not authorize child-agent dispatch. Native availability and invocation depend on the installed OpenCode version and configuration.
