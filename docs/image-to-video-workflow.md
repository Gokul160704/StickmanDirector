# Retired image-to-video workflow record

This filename is retained for compatibility with older links. It is a historical, non-authoritative record only. The approved StickmanDirector production contract does not generate Google Flow video clips, image-to-video clips, animated scenes, or motion prompt packs.

The current path is still-image-only and uses the explicitly selected approved
still provider (Flow by default; separately authorized alternatives are covered
by the provider-neutral contracts):

1. Approve the script and ordered Boords storyboard.
2. Create and review recurring character, prop, and environment references.
3. Generate or import and review one complete still illustration per approved storyboard scene, preserving provider provenance and any visible watermark.
4. Attach approved stills to Boords and record provenance in `episode.json`.
5. Produce approved narration and timing with the established Gemini TTS workflow and, where applicable, `flow_transcribe`.
6. Assemble the approved stills, narration, and captions locally with FFmpeg.

Do not copy or revive the former motion instructions. Historical image-to-video experiments remain in Git history and older audit records only; they are not supported production behavior, model choices, provider choices, or approval gates.
