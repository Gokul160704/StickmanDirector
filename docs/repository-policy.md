# Repository content policy

## Commit by default

- `AGENTS.md`, `AUDIO.md`, the root README, and reusable workflow documentation.
- Generic scripts and blank/example templates that contain no episode-specific or secret material.

## Keep local by default

- Everything beneath `projects/` and `output/`, including scripts, storyboards, prompts, references, generated images, audio, captions, and rendered video.
- API credentials, cookies, signed URLs, exports, temporary files, and account-specific data.

This default preserves the existing episode work on the current computer while preventing accidental publication of generated or potentially rights-sensitive content. If a specific original project should be shared later, review and select only those files deliberately, then adjust the ignore policy for that selection.
